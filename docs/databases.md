# Databases Standard

For data storage, the following databases are permitted:

::: info PostgreSQL via CNPG
For relational data storage

Preferred for most applications due to its robustness and feature set
:::

::: tip Redis
For caching and session management
:::

::: info ClickHouse
For analytics and high-performance read-heavy workloads
:::
