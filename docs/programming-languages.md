# Programming Languages Standard

For backend development the following programming languages are permitted:

- Go
  - Gin
  - For general backend services
  - See template repository for more details
- Rust
  - For high performance backend services where latency is critical

For frontend development the following programming languages are permitted:

- TypeScript
  - React
  - Vite
  - Tanstack Router
  - Tanstack Query
  - See template repository for more details
- Dart (Flutter)

Strictly Perhibited:

- Python
  - Not allowed for servers nor scripts.

- Javascript
  - Not allwed for servers, scripts or frontend.

- NodeJS
  - There should be no javascript running on the server.
